# شوبان بوار AI

نموذج أولي متجاوب للجوال والكمبيوتر، يدعم العربية والإنجليزية ويحتوي على مساعد صوتي تجريبي باسم سوسو.

## المتوفر

- تصميم متجاوب.
- دعم RTL وLTR.
- محادثة محلية تجريبية.
- نطق وإدخال صوتي حسب دعم المتصفح.
- تمهيد لخطة مجانية واشتراكات.

## ملاحظة

الذكاء الاصطناعي السحابي والحسابات والدفع تحتاج خادماً خلفياً آمناً.
